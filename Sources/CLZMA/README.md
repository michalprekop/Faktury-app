# liblzma

Unmodified XZ Utils 5.8.3 API headers (0BSD), from the installed Homebrew xz
package. Only the stable liblzma 5.x API is used. The app links Apple's system
`/usr/lib/liblzma.5.dylib`, not Homebrew, and needs no extra runtime installation.
